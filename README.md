# Educational Keylogger (Python)

## ⚠️ Disclaimer
This project is for educational and ethical use only. Never use this on systems you don’t own or without explicit permission.

## 📚 Objective
Simulate how keyloggers work to understand their risk and help design better cybersecurity defenses.

## 💡 Features
- Logs all keystrokes in real-time
- Handles both standard and special keys
- Log rotation to prevent large files
- Timestamped entries
- Optional encryption using Fernet (AES)
- Ethical-use disclaimer and stealth mode (Windows)

## 🚀 Run
```bash
cd src
python keylogger.py

ctrl + c to exit execution

check keystrokes.txt for captured data
